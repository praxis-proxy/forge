# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | No (Alpha) |

## Reporting a vulnerability

Report security vulnerabilities to: **security at praxis dot fast**

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Severity classification

- **Critical**: Remote code execution, credential exposure
- **High**: Privilege escalation, data exfiltration
- **Medium**: Denial of service, information disclosure
- **Low**: Minor issues with limited impact

## Safe harbor

Security research conducted in good faith is authorized. We will not
pursue legal action against researchers who follow responsible disclosure
practices.
